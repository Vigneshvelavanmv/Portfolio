# 🌐 Personal Portfolio Website

This repository contains my **personal portfolio website**, created using **HTML5** and **CSS3**.  
The project showcases my skills, projects, and contact details through a clean, elegant, and responsive layout.  
It serves as a digital introduction to who I am, what I build, and how to reach me.

---

## 🧾 Project Overview

The **Portfolio Website** is designed to present my work and personal profile in a minimal yet professional way.  
It contains **two main pages**:

1. **Home Page** – Includes my introduction, skills, and project highlights.  
2. **Contact Page** – Provides a simple section to reach out or connect with me.

This project demonstrates the use of **semantic HTML**, **flexbox layout**, and **basic CSS styling techniques** to create a visually appealing and easy-to-navigate website.

---

## 🧠 Features

- ✅ Two-page static portfolio (Home & Contact)  
- 🎨 Clean and modern UI using only HTML & CSS  
- 📱 Responsive design compatible with desktop and mobile screens  
- 💼 Project showcase section highlighting real-time projects  
- 📬 Contact section for easy communication  

---

## 🛠️ Tech Stack

1. **HTML5** - Page structure and content.
2. **CSS3** - Styling, colors, layout, and responsiveness.
